Building the IP Address Tracker helped me see how a project can come together one step at a time. I started with the HTML structure, then added the styles to match the desktop and mobile designs. After that, I worked on the JavaScript and map. Keeping the steps small made the project feel more manageable, and I could focus on one part before moving on to the next. One challenge was getting the IPify API key into the app without putting it in the browser code. I learned that a key in frontend JavaScript is visible to anyone who opens the site. To avoid that, I used a small Node.js server to read the key from the `.env` file and make requests to IPify. That also meant I had to run the project through the server instead of opening the HTML file directly. Another challenge was getting the map and the information card to display together correctly. Leaflet needs its own stylesheet and a map container with a set height. The map layers also appeared over the card at first, so I adjusted the stacking order in CSS. I used the API response to update the IP details and move the map marker when someone searches. If I continued improving the project, I would test more screen sizes and add clearer feedback for less common API errors. I would also learn more about deploying the app, since the local Node server is for development and should not be used as-is for a public site. Overall, I’m happy that the finished app connects the form, API, and map, and I understand the pieces better than I did when I started.
