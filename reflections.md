Building the IP Address Tracker helped me see how a project can come together one step at a time. I started with the HTML structure, then added the styles to match the desktop and mobile designs. After that, I worked on the JavaScript and map. Keeping the steps small made the project feel more manageable, and I could focus on one part before moving on to the next. One challenge was getting the IPify API key into the app without putting it in the browser code. I learned that a key in frontend JavaScript is visible to anyone who opens the site. To avoid that, I used a small Node.js server to read the key from the `.env` file and make requests to IPify. That also meant I had to run the project through the server instead of opening the HTML file directly.
