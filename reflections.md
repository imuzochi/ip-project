Building the IP Address Tracker helped me see how a project can come together one step at a time. I started with the HTML structure, then added the styles to match the desktop and mobile designs. After that, I worked on the JavaScript and map. Keeping the steps small made the project feel more manageable, and I could focus on one part before moving on to the next. One challenge was getting the IPify API key into the app without putting it in the browser code.
